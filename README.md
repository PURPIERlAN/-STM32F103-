# STM32F103C8T6 贪吃蛇

## 项目简介

这是一个基于 STM32F103C8T6 的 LED 点阵贪吃蛇项目。项目以 Keil5 工程组织，使用 MAX7219 驱动 8×8 LED 点阵显示游戏画面，并通过 OLED 显示分数和游戏状态。

## 硬件与开发环境

- 硬件平台：STM32F103C8T6
- 开发环境：Keil MDK 5
- OLED：SSD1306，用于显示分数与游戏状态
- LED 点阵：MAX7219 驱动 8×8 点阵，呈现贪吃蛇游戏画面

## 功能

- 点阵贪吃蛇游戏，支持方向控制、成长和碰撞判定
- OLED 显示当前分数与游戏状态
- 按键输入及蜂鸣器反馈
